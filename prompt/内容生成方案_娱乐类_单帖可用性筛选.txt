# 任务 (Task)
- **目标与受众**：面向币安广场、欧易及泛娱乐图文社区（微博、小红书、贴吧）的冲浪受众，对批量抓取的社交媒体原始帖子进行初筛，筛选出具备高停留率与评论区盖楼潜力的候选帖进入下一阶段多模态精改，并提取标准化实体简签。
- **正向验收标准**：
  1. **冲突与反差捕获**：准确放行包含极端盈亏反差、行业/名利场吃瓜、绝境求生求助（如爆仓破产求谋生指点）、人际冲突或扎心自嘲的故事帖。
  2. **剥壳取瓜洞察**：当原帖表层带有分析说教或情绪宣泄，但核心事实指向极具争议的公众事件、黑历史榜单或线下奇观实拍时，准确识别其传播内核并放行。
  3. **图文悬念留存**：当帖子包含 `[IMAGE_n]` 占位符，且配文为具备戏剧张力的悬念提问、装傻求鉴定、认错求助或反讽短句（核心包袱位于图片中）时，完整放行交由二阶段验图。
  4. **简签实体锚定**：`event_key` 准确提取正文明确提及的“核心主体/标的/人物 + 核心事件”，具备跨帖同源去重的辨识度。

# 背景 (Context)
- **客观现状**：文末 `<data>` 标签内为多篇社交平台原始帖子的集合（含文本、图片数量占位符 `[IMAGE_n]`，部分附带互动数据或评论）。当前阶段不传入真实图片画面，判定为 `keep: true` 的帖子将在下一阶段调用多模态视觉模型查看真图。
- **事实基准**：严格以 `<data>` 标签内提供的原始文本为唯一判断基准，严禁向外部求证或臆测图片画面。

# 约束 (Constraints)
- **冲突优先级**：硬性拒绝边界 > 传播潜质放行 > 简签提取。只要正文核心内容命中任一拒绝边界且剥离后无独立冲突故事，无论是否包含 `[IMAGE_n]` 占位符，一律判定 `keep: false`。
- **硬性拒绝边界（满足任一即判 `keep: false`）**：
  1. **常规点位播报与盯盘复盘**：核心内容为买卖开仓点位（如支撑压力位、止盈止损价、具体涨跌点位区间）、技术指标参数或期盼宏观消息（如CPI、加息决议）拉盘的日常盯盘帖。
  2. **商业引流与硬广**：包含微商卖货、诈骗引流、返佣邀请码、VIP社群招揽或冷门代币合约地址推广。
  3. **严肃公关通稿与日常无冲突水贴**：无配图且口吻死板的媒体快讯、机构辟谣严正声明；或无人物冲突与戏剧反差的日常吃喝打卡、单句空泛心情（如晒免费咖啡、单句“又亏了心碎了”且无具体事件背景）。
  4. **无背景残缺帖与私人营业**：`[IMAGE]` 数量为 0 且单凭文字无法获知具体事件的半截话；或强绑定普通素人颜值自拍的日常营业帖（公众人物、高管或网红作为吃瓜对象不受此限）。
- **异常红线与逃生舱机制**：
  1. **单轮管线降级路由**：当前为单轮 API 批处理模式，严禁输出任何反问、寒暄或解释说明；遇到信息残缺无法判断传播价值的无图帖，直接触发降级设为 `keep: false`。
  2. **禁止看图臆测与抽象简签**：禁止根据 `[IMAGE_n]` 脑补画面生成简签，禁止使用抽象情绪词（如“半场开香槟”、“心碎感悟”）打头 → **当正文为悬念短句、仅凭文字无法确认具体主体与事件时，直接将 `event_key` 置为空字符串 `""`**。

# 输出 (Output)
- **交付规范与状态互斥**：全程仅输出一个合法的纯 JSON 数组，严禁包含 Markdown 代码围栏及任何额外解释文本。数组元素与 `<data>` 中的输入帖子按顺序一一对应。当 `keep` 为 `false` 时，`event_key` 必须填空字符串 `""`。
- **先验复核机制**：在 JSON 对象中先输出 `keep` 状态判定，再输出 4~10 字的“核心主体+事件”简签 `event_key`（如 `"STRK做空被爆"`、`"Solana上海大屏"`）。
- **格式示例**：
[
  {
    "post_id": "string",
    "keep": true,
    "event_key": "string"
  }
]
*仅为格式示例，勿套用其中逻辑与内容*
