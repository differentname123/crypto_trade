# 任务 (Task)
- **目标与受众**：面向币安广场、欧易及泛娱乐图文社区的冲浪受众，对批量抓取的社交媒体原始帖子进行低成本初筛，放行具备高停留率与评论区盖楼潜力的活人感候选帖进入下一阶段多模态精改，并提取标准化实体简签。
- **正向验收标准**：
  1. **个体冲突与反差捕获**：准确放行包含个体真实极端盈亏、名利场/行业撕逼吃瓜、绝境求生求助、人际冲突或扎心自嘲的活人故事帖。
  2. **剥壳取瓜洞察**：当原帖表层带有情绪宣泄或个人吐槽，但核心事实指向极具争议的公众人物事件、行业奇葩乱象或线下奇观实拍时，准确识别其传播内核并放行。
  3. **图文悬念留存**：当帖子包含 `[IMAGE_n]` 占位符，且配文为具备戏剧张力的悬念提问、装傻求鉴定、破防短句或反讽吐槽（核心包袱位于图片中）时，完整放行交由二阶段验图。
  4. **简签实体锚定**：`event_key` 准确提取正文明确提及的“核心主体/人物 + 具体事件”，具备跨帖同源去重的辨识度。

# 背景 (Context)
- **客观现状**：文末 `<data>` 标签内为多篇社交平台原始帖子的集合（含文本、图片占位符 `[IMAGE_n]`，部分附带互动数据）。当前阶段不传入真实图片画面，判定为 `keep: true` 的帖子将在下一阶段调用多模态视觉模型查看真图。
- **事实基准**：严格以 `<data>` 标签内提供的原始文本为唯一判断基准，严禁向外部求证或臆测图片画面。

# 约束 (Constraints)
- **冲突优先级**：硬性拒绝边界 > 传播潜质放行 > 简签提取。只要正文命中任一硬性拒绝边界且剥离后无独立吃瓜故事，无论开头多么情绪化或是否包含 `[IMAGE_n]`，一律一票否决判定 `keep: false`。
- **准入与硬性边界（满足任一即判 `keep: false`）**：
  1. **点位盯盘与宏观数据播报**：正文包含具体 K 线周期、支撑压力位区间、开平仓点位指导（含文末夹带挂单点位），或通篇盘点全网清算金额占比、涨跌幅排行榜单（如 Top Losers/Gainers）、链上资金流向等非个人实盘经历的市场分析与外文快讯模板。
  2. **商业引流与硬广**：包含微商卖货、诈骗引流、返佣邀请码、VIP 社群招揽或冷门代币合约地址推广。
  3. **带单营业与粉丝家书**：交易员/主播向粉丝汇报近期带单胜率、实盘心理负担、停更休假计划、直播时间预告，或普通素人日常颜值自拍打卡。
  4. **严肃通稿与无背景残缺水贴**：口吻死板的媒体快讯、机构公关声明；或 `[IMAGE]` 数量为 0 且单凭文字无法获知具体冲突事件的单句空泛感慨（如无图且仅一句“又亏了心碎了”）。
- **异常红线与逃生舱机制**：
  1. **单轮管线降级路由**：当前为单轮 API 批处理模式，严禁输出任何反问、寒暄或解释说明；遇到信息残缺无法判断传播价值的无图帖，直接触发降级设为 `keep: false`。
  2. **禁止看图臆测与抽象简签**：禁止根据 `[IMAGE_n]` 脑补画面生成简签，禁止使用抽象情绪词（如“半场开香槟”、“心碎感悟”）充当简签 → **当正文为悬念短句、仅凭文字无法确认具体主体与事件时，直接将 `event_key` 置为空字符串 `""`**。

# 输出 (Output)
- **交付规范与状态互斥**：全程仅输出一个合法的纯 JSON 数组，严禁包含 Markdown 代码围栏及任何额外解释文本。数组元素与 `<data>` 中的输入帖子按顺序一一对应。当 `keep` 为 `false` 时，`event_key` 必须填空字符串 `""`。
- **先验复核机制（自回归顺序强约束）**：在 JSON 对象中先输出 `keep` 状态判定，再输出 4~10 字的“核心主体+事件”简签 `event_key`。
- **格式示例**：
[
  {
    "post_id": "string",
    "keep": true,
    "event_key": "string"
  }
]
*仅为格式示例，勿套用其中逻辑与内容*
