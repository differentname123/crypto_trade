# 任务 (Task)
- **目标与受众**：面向微博、小红书、贴吧的泛娱乐大众受众，对批量抓取的社交媒体原始帖子（仅含文本与图片占位符）进行初筛过滤，筛选出具备大众传播潜力的候选帖进入下一阶段多模态精改，并提取客观事件简签。
- **验收标准**：
  1. **零噪音漏网**：所有纯交易信号、买卖点位预测、宏观复盘通稿、商业引流硬广、强私人身份绑定帖以及无背景的纯文字半截话，全部被拦截（`keep: false`）。
  2. **零潜质误杀**：包含极端盈亏反差、奇葩吃瓜、人际冲突的文本帖，以及排除交易/广告噪音后核心看点位于图片中的短句悬念帖，全部被放行（`keep: true`）。
  3. **简签客观无臆测**：`event_key` 严格基于正文明确提及的客观主体与事件提取，无看图瞎猜。

# 背景 (Context)
- **客观现状**：文末 `<data>` 标签内为多篇社交平台原始帖子的集合。当前阶段仅提供纯文本及图片数量占位符（如 `[IMAGE_1]`），不提供真实图片画面。下一阶段将调用高成本多模态视觉模型直接查看 `keep: true` 帖子的真实配图。原始帖来自金融与泛生活混杂社区，包含大量交易点位噪音、返佣软广及平台特定代码标签。

# 约束 (Constraints)
- **冲突优先级**：**拒绝边界优先级绝对高于放行边界**。只要正文命中任一拒绝边界，无论是否包含 `[IMAGE_n]` 占位符，一律判定 `keep: false`。
- **硬性拒绝边界（满足任一即判 `keep: false`）**：
  1. **交易信号与行情播报**：核心内容为买卖建议、开仓/止盈/止损点位（如 Entry/TP/SL、支撑/压力位、减仓比例、目标价、黄金分割）、技术指标参数、涨跌幅榜单或目标达成庆功（含全英文交易帖），且剥离后无独立的人物故事或生活冲突。
  2. **商业引流与硬广**：包含微商卖货、诈骗引流、邀请码、手续费返佣、VIP社群/聊天室招揽或冷门代币合约地址，且剥离广告后无独立故事或笑点。
  3. **宏观通稿与普通打卡**：通篇复述 CPI、加息、美债收益率、板块轮动等财经分析，或无极端数字反差的普通散户日常操作汇报。
  4. **无图残缺帖**：`[IMAGE]` 数量为 0，且正文缺乏完整事件背景（如没头没尾的劝架、空泛感慨或问候，圈外读者仅凭文字无法获知具体事件）。
  5. **强身份锁死帖**：必须依赖原帖作者特定私人身份或真人露脸才成立的日常营业帖（注：公开人物或网红作为被吃瓜讨论的对象不受此限）。
- **硬性放行边界（排除上述拒绝项后，满足任一即判 `keep: true`）**：
  1. 正文自带具体的暴富暴亏极端反差、奇葩吃瓜、人性潜规则、家庭/职场冲突或自嘲痛点。
  2. 包含 `[IMAGE_n]` 占位符，且配文为简短的生活化吐槽、装傻求证、地域提问或情绪独白（核心故事或视觉反转位于图片中）。
- **异常与红线**：禁止根据图片占位符猜测图片内容；仅凭正文无法确认具体事件时，`event_key` 必须填空字符串 `""`。

# 输出 (Output)
- **交付规范**：仅输出一个合法的纯 JSON 数组，禁止包含 Markdown 代码块标识（如 ```json）及任何额外解释文本。数组元素与文末 `<data>` 中的输入帖子按顺序一一对应。
- **复核机制**：在 `event_key` 中输出 4~10 字的“核心主体+事件”简签作为同源去重依据；无明确事件则置空。
- **格式示例**：
[
  {
    "post_id": "string",
    "keep": true,
    "event_key": "string"
  }
]
*仅为格式示例，勿套用其中逻辑*
