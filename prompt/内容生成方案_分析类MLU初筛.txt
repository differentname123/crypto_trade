# 任务 (Task)

- **做什么 / 给谁用**：从下游“加密货币多模态论据精提系统”的数据网关视角，对末尾 `<data>` 标签中批量输入的社交帖子进行前置初筛过滤。剔除大概率不含有效分析论据（`evidences`）的噪音帖，仅将具备提取潜力的帖子放行至下游多模态提取环节。
- **验收标准**：
  1. **有效论据三要素基准**：下游合格论据必须同时闭环具备 **【明确标的与多空/震荡立场 (`stance`) + 可核查的客观事实 (`core_fact`) + 因果推导机制 (`logic_link`)】**。其中，有效立场（`stance`）包含直接看多/看空/看震荡，以及**基于明确方向倾向的右侧条件式计划**（如判定趋势偏多但短期不宜追高、需等突破或回踩特定价位确认再接多；或判定高位派发偏空、需等深跌特定幅度或守住前低再看）。
  2. **无图帖（`images` 为 `[]`）放行标准（`no_evidence: false`）**：未触发 `# 约束` 红线，且纯文本独立凑齐三要素闭环——明确具体币种或宏观市场的方向倾向、包含具体可核查事实（明确周期的K线高低点结构、具体关键价位突破/受阻表现、技术指标数值/状态、链上/合约持仓量OI/资金费率数据、具名机构/交易所/宏观催化事件），并阐明“由该客观事实推导出该方向倾向”的因果传导机制。
  3. **含图帖（`images` 非空）放行标准（`no_evidence: false`）**：未触发 `# 约束` 红线，且满足以下任一条件：
     - 正文已独立凑齐上述三要素闭环；
     - 正文给出了明确的多空/震荡倾向，并指明了具体的**强图表/数据观测维度**（必须至少包含以下一项：明确的时间周期如 15m/1h/4h/日线、具体的关键支撑/阻力价位数值、具体的技术形态/指标名称如均线MA/RSI背离/箱体颈线/趋势线/需求区，或具体的订单流/持仓量/资金费率/链上筹码维度），使缺失的微观图表数值或K线形态具备由配图补全的合理预期。
  4. **键值映射完整性**：输出 JSON 的顶层 Key 集合必须与末尾 `<data>` 中的 `post_id` 集合 100% 一一对应，零遗漏、零新增。

# 背景 (Context)

- **系统现状与数据假设**：
  1. **图文分离机制**：本环节为低成本纯文本过滤层，不传入真实图片像素，仅将原帖配图抽离为占位符字符串数组 `images`（如 `[]` 代表无配图，`["image1", "image2"]` 代表原帖含 2 张配图）。
  2. **社区噪音分布特征**：输入源包含大量自动化机器脚本与低质水帖，典型噪音画像包括：
     - **三段式矩阵号伪分析帖**：播报单一价格/涨跌幅/均线突破快照，拼接一句无具体机制支撑的万金油操作套话（如“我会等回踩确认不急着追”）或通用风控鸡汤，末尾抛给读者互动提问（如“评论区留下你的判断”）及免责声明；
     - **英文模板化口号喊单帖**：通篇堆砌空泛情绪形容词（如 `strong bullish momentum`、`massive volume breakout`、`buyers are dominating`、`sellers going crazy`）与点位表，但无具体K线周期、无关键支撑阻力分析或具体指标依据，配图多为海报或涨跌幅卡片而非技术图表；
     - **同义反复与车轱辘话帖**：用充要条件同义反复代替走势判断（如“关键看回踩能不能接住，接住了就是真突破，接不住就凉凉”）；
     - **其他常见社区噪音**：纯点位喊单、晒单引流、持仓求助、爆仓情绪宣泄、日常八卦，以及因英文缩写重名导致的跨领域误抓帖。
  3. **输入字段定义**：位于提示词最末尾的 `<data>` 标签内为 JSON 数组，单元素包含 `post_id`（[String] 帖子唯一标识）、`text_content`（[String] 剥离媒体链接后的正文）、`images`（[Array] 图片占位符列表）。

# 约束 (Constraints)

- **硬性边界与冲突裁决优先级**：
  1. **【点位策略】与【分析依据】并存时，以分析依据优先**：若帖子包含交易点位表（`Entry/TP/SL`），但正文同时阐述了具体的盘面事实、强图表观测维度或风险机制（如明确某周期突破/受阻、均线/RSI指标状态、需求区卖压衰竭、空头施压支撑位及日线前低反抽风险），优先适用放行标准（判为 `false`）；若除点位表外仅有无周期、无具体结构或指标支撑的空泛口号（如“直接多进去”、“strong bullish momentum”、“massive rejection”），无论是否有图，优先按纯喊单淘汰（判为 `true`）。
  2. **【客观数据】与【立场/推导缺失】冲突时，以三要素闭环优先**：即使正文包含精确的客观数据（如资金费率数值、持仓量变化、成交额倍数、24h涨跌幅、站上某均线数值），只要缺失明确的多空/震荡倾向（`stance`）或缺失因果推导机制（`logic_link`），一律优先执行淘汰（判为 `true`）。
  3. **【主力/筹码推演】与【无据臆断】冲突时，以客观数据锚定优先**：若正文提及“主力换手/出货/吸筹/逼空”，且给出了具体的可核查数据支撑（如30天涨幅与24h回撤伴随持仓量未减、成交额与市值比值异常、极端负费率、链上大额转出交易所），属于有效量价筹码推导，优先适用放行标准（判为 `false`）；仅当无任何客观数据支撑而纯凭主观臆测庄家动作时，按无据臆断淘汰（判为 `true`）。

- **异常与红线（满足任一条件，无论 `images` 是否为空，强制判定 `no_evidence: true`）**：
  1. **有数据但无推导的播报/科普/套话/提问**：仅罗列单币或多币涨跌幅榜单（Top Gainers/Losers）、短线成交额/价格破位/单一均线快照，后接指标概念定义科普、通用风控说教（如“保住本金”、“止损不丢人”）、缺乏具体后续机制的万金油单句表态（如仅写一句“我会等一次回踩确认，不急着追”）、同义反复废话（如“回踩接住了就是真突破，接不住就凉凉”）或抛给读者的互动提问（如“真突破还是脉冲？你怎么看？”、“评论区留下你的判断”）。
  2. **明确放弃立场与无倾向双向假设**：作者在正文中明确表态不做方向判断或看不懂走势（如“我就先去干点别的”、“暂时不急着下结论，说不好”），或无当下主方向倾向的对称式双向模棱两可推演（如“如果跌破X就做空，突破Y就做多”）。
  3. **纯困惑提问与持仓求助**：通篇仅为向他人请教异动原因（如“卖盘比买盘多几倍到底靠啥涨的？求懂哥解惑”）、询问代币属性（如“这两个币是妖币吗”）或被套持仓求救。
  4. **纯机械喊单、空泛口号与无据臆断**：仅罗列方向、入场、止盈止损点位；或仅堆砌无具体周期、无具体价位结构支撑的情绪化口号（如 `strong bullish momentum with massive volume breakout`、“一手多情况不妙就跑”、“反弹就做空”）；或无客观数据支撑仅凭主观臆测庄家动作（如“庄在护盘肯定爆拉”、“平台把数据透明给狗庄”）。
  5. **晒单引流与营销水帖**：炫耀历史收益率/止盈交割单、引导看主页/进群/直播间跟单、扫链合约地址喊单、空投交互教程、出金U商筛选教程、项目方纯公关宣传软文。
  6. **非当下加密行情分析体裁**：爆仓亏损情绪宣泄、辱骂庄家/代币、餐饮旅游日常、圈内或职场八卦讨论（如主播假酒事件、大厂员工篡改代码事件）、传统游戏/科技公司裁员新闻、历史轶事回顾，以及未阐述多空价格传导机制的纯单句消息快讯。
  7. **跨界标签乌龙**：正文新闻主体与所挂代币标签非同一事物（如将宏观新闻“韩国央行利率点阵图 K-DOT Plot”误贴上波卡 `$DOT` 标签）。
  8. **禁止为无图帖脑补事实**：当 `images` 为 `[]` 时，严格基于 `text_content` 字面信息核验，禁止假设任何未写明的盘面形态或数据。

# 输出 (Output)

- **交付规范**：
  - 仅输出一个合法的纯 JSON 对象（Dictionary），严禁包含 Markdown 代码块标识（如 ```json）、思考过程或任何前后置说明文字。
  - 顶层 Key 为输入的 `post_id`，Value 为包含以下两个字段的对象：
    - `no_evidence` [Boolean]：`true` 代表大概率无有效论据（淘汰）；`false` 代表可能含有效论据（放行）。
    - `reason` [String]：简明判定依据，字数严格控制在 35 字以内。
- **复核机制**：
  - `reason` 字段供人工抽检使用，必须直接点明**三要素（立场/事实/推导）的闭环情况**、**命中的具体淘汰红线类型**或**配图补全事实的合理性**，禁止复述原帖句子或展开推导过程。
- **格式示例**（*仅为格式示例，勿套用其中逻辑*）：
  - 输入示例：
    `[{"post_id": "1001", "text_content": "示例文本A", "images": ["image1"]}, {"post_id": "1002", "text_content": "示例文本B", "images": []}]`
  - 输出示例：
    `{"1001": {"no_evidence": false, "reason": "具备明确立场与具体周期支撑维度，微观形态数据可由配图补全"}, "1002": {"no_evidence": true, "reason": "无配图且缺失因果推导，命中数据快照拼接通用套话与互动提问红线"}}`
